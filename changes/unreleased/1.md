### Fixed

- OMO slash commands execute on OpenCode V2. Every command was registered with an `execute` callback that only wrote a log line, so `/goal`, `/ulw-execute`, `/refactor`, `/hyperplan`, `/handoff`, `/remove-ai-slops`, `/stop-continuation` and every skill-backed command did nothing under V2. The template is now expanded (`$ARGUMENTS`, `$SESSION_ID`, `$TIMESTAMP`), the command's declared agent is selected, and the result is dispatched into the session.
- A remote MCP server without headers no longer disables the whole plugin. OpenCode V2 validates MCP server configs strictly, where an explicit `undefined` for an optional object field is a hard `SchemaError`; the transform threw, and the host responded with "disabled plugin after transform failure", killing every OMO tool, agent and command for that session.
- The V2 client shim passes `session.prompt` its real single-object signature, unwraps the `{location, data}` envelope returned by `agent.list()`, and distinguishes synchronous `prompt` from fire-and-forget `promptAsync`.
- The agent transform callback is synchronous again. The host invokes it lazily on every agent-list recompute and does not await it.
