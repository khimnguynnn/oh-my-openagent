### Fixed

- Model context limits, image-capable model detection, and the Anthropic 1M-context flag work on OpenCode V2. The config pipeline derives all three from the provider map it is handed, and the V2 bridge handed it an empty object, so every one of those caches was built from nothing: auto-compaction thresholds, tool-output truncation, and the multimodal fallback chain all ran without the data they read. V2 keeps the same facts in its own catalog, so the bridge now reads it and fills the map before the pipeline runs.
- A model configured without a provider no longer fails to route on OpenCode V2. Any model string without a `/` was resolved to `anthropic`, so naming `gpt-5.6-sol` produced `anthropic/gpt-5.6-sol` and the request was refused. The provider is now looked up in the live catalog, and when no provider serves the model the agent keeps the model the host already resolved instead of being pointed at one that cannot answer.
