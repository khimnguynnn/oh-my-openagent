### Fixed

- `/security-research` and `/security-review` work on OpenCode V2. Those two skills exist as code rather than files, and V1 made them visible by running a small HTTP server whose URL it appended to `config.skills.urls` for the host to fetch. V2 has no `config` domain on the plugin context and never reads `skills`, so on V2 neither skill existed at all: the slash commands, the skill itself, and the Team Mode security workflow it documents were unreachable. V2 does expose a real `skill.add`, so the entries are now registered directly with the shape the host reports. `disabled_skills` behaves exactly as on V1 because selection reuses the same source of truth.
