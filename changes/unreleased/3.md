### Fixed

- OpenCode V2 plugins get working session lookups: V2 session calls take a `{ sessionID }` options object, and the bridge was passing the bare id, so session detail, history, abort and interrupt were all rejected. Agent tool permissions now refresh and subagent parent detection works again.
- `session_list` and the btw-side session picker work on OpenCode V2. The bridge's client shim never exposed `session.list`, and session records carried their directory under `location` while the directory filter read a flat `directory`.
- OS notifications reach the platform helper on OpenCode V2. The bridge passed a callable no-op as the shell helper, which suppressed the `execFile` fallback and failed on every send.
- Skill loading no longer warns about optional skill roots that were never created (`~/.claude/skills`, `~/.agents/skills`, `~/.config/opencode/skill`).
