### Changed

- `@opencode/plugin` moves from 2.0.32 to 2.3.2, so the OpenCode V2 bridge compiles against the same contract the host binary ships. The pin sat three minor versions behind the runtime, which meant the type contract validated during development was not the one the bridge actually met at runtime. Both the workspace root and `packages/omo-opencode` pinned it, so both move together; bumping one alone leaves the root resolving the old contract.
