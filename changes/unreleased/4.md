### Fixed

- `session_list` returns real sessions on OpenCode V2. The bridge synthesized a `serverUrl` of `http://localhost:4096`, which V2 never provides and the host does not bind, so the session SDK client was refused, the error was classified as unavailable, and listing silently fell back to OpenCode's legacy JSON storage that V2 never writes. Every session list came back empty.
- `session_read` and `session_info` work on OpenCode V2. V2 `session.context` answers a flat entry list while the V1 readers expect `{ info, parts }` messages and drop entries without `info.id`, so every session read as empty. Session entries are now mapped to the V1 shape, with assistant `reasoning` and `tool` content becoming the part types the formatter renders.
- OMO tools receive an `AbortSignal` as `abort` on OpenCode V2. The bridge passed an empty function where the V1 tool context carries a signal, so any tool calling `abort.throwIfAborted()` failed.
