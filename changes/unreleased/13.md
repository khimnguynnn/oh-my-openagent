The OpenCode V2 sidebar now lists one row per agent instead of one row per session, and
clicking a row opens it. A run of four same-named subagents used to print four nearly
identical lines that wrapped onto extra rows; it now reads as `explore ·4`, and the session
ids underneath appear only when you ask for them. Clicking a session id switches to that
session.

- Agent rows collapse by name with a session count, and the busy session decides the row's glyph and colour.
- The model id no longer occupies the collapsed row, which is what pushed titles onto a second line.
- Clicking a row expands its sessions; clicking a session id navigates to it.
- Titles are truncated to the sidebar's measured width rather than a fixed 24 columns.
- A row that holds a single session is not clickable, so no click leads nowhere.
