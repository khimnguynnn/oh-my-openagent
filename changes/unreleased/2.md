### Fixed

- Every OMO tool is available again on OpenCode V2. OMO tools declare their arguments with `tool.schema`, the zod copy bundled inside `@opencode-ai/plugin`, while the rest of the repository resolves the root zod. The V2 bridge handed those raw Zod objects to the host, which converts them with its own zod copy; a foreign schema makes that conversion throw `seen.ref`, and the host answers by logging `Skipping invalid tool registration` and dropping the tool. All 14 tools (`grep`, `glob`, `session_list`, `session_read`, `session_search`, `session_info`, `background_output`, `background_cancel`, `call_omo_agent`, `look_at`, `task`, `skill_mcp`, `skill`, `interactive_bash`) were rejected in every V2 session. The bridge now converts tool arguments to plain JSON Schema itself, preserving field descriptions that a cross-copy conversion drops even when it does not throw.
